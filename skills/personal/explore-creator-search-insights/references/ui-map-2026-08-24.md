# Creator Search Insights UI map — 2026-08-24

Use this map only as a navigation hint from one observed Android build/account state. Verify every label and control on the live screen. Interpret “not observed” as scoped to the cited surface, not absent from all accounts or builds.

## Observed navigation

Use this direct path when present:

`TikTok → Profile → ☰ profile menu → Creator Search Insights`

`Creator Search Insights` was a direct menu item under the non-clickable section heading `Creation & business tools`, beside `TikTok Studio`. No separate `Creator Tools` intermediary was present.

If the direct item is absent, the requested fallback is to search TikTok for `creator search insights` and inspect the top tool result. This fallback was not verified in the 2026-08-24 capture.

The header showed a search icon and quick tools `AI outline`, `AI canvas`, `Analytics`, `Saved`, and `All tools`, followed by a promotional carousel.

The three list-mode labels were:

1. `All`

No `High % Gap`, region, date, or labeled sort option appeared in the examined Suggested-list filter sheets. Some rows showed `High content gap`, but it was a badge rather than a selectable filter. A circular-arrow icon appeared to be refresh/reload; no visible text label established its semantics.

## List rows

A row could show:

- exact term/topic text;
- a gray flame value and unlabeled sparkline;
- a blue upward triangle and percentage;
- secondary text such as `Great for a first post`, `High content gap`, `Performed well`, `Popular with your followers`, `Recently explored`, `Trending in ET`, or a `+ posts` count;
- bookmark and create-video row controls, which are prohibited interaction targets.

The sampled detail grouped the flame value and blue percentage inside `Search popularity`. The UI did not explicitly call the percentage growth, change, or gap size and did not state its comparison basis. Rows had a display order but no numeric rank or labeled sorting criterion.

The date selector was titled `Select date range` and offered `Last 7 days`, `Last 30 days`, `Last 60 days`, `Last 6 months`, and `Custom`.

Numbers on sampled Related videos appeared beside heart icons and were engagement/heart counts, not explicit video-view counts. No visible label identified the prose under `What viewers are searching` as AI-generated.
